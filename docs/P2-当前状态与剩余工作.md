## 1. 已完成能力与复用入口

| 能力 | 实现位置 | 既有边界 |
| --- | --- | --- |
| 正式存储与草稿 | `mail-storage`、`mail-daemon/storage.rs`；schema8、SQLite 单写者、私有对象、后台保存与恢复 | 不直接从 UI 打开数据库 |
| 通用账号 | `mail-service/accounts.rs`、`credentials.rs`、UI `accounts.rs` | 单账号 IMAP/SMTP、Secret Service；无 OAuth |
| 同步与邮件操作 | `mail-service/sync.rs`、`actions.rs`、`mail-daemon/sync_engine.rs` | 启动立即同步目录与可选文件夹；之后60秒轮询，失败退避；无 IDLE |
| 文件夹/搜索/阅读 | `mailbox.rs` + `mailbox_view.rs`、`reader.rs`、`mail-content` | 选信直接阅读，缓存优先；无缓存时整封 MIME 下载≤8MiB；远程图片需单封授权 |
| 写信/回复/转发 | `composer*`、`reply.rs`、受控 Draft | 多草稿、To/Cc/Bcc、附件、HTML 清理；中文斜体仍有字形缺口 |
| 发送与已发副本 | `mail-daemon/sending.rs`、`mail-storage/outbox.rs`、服务层 | 显式确认；禁止自动重发；APPEND 只重试副本，不再次 SMTP |
| 任务/设置/生命周期 | `send_tasks.rs`、`settings.rs`、`lifecycle.rs` | 关窗后台继续；托盘/单实例；明暗、字号、密度与减少动态 |

模块地图与复用规则见 [项目全貌](项目全貌与模块复用说明.md)，阶段交付见 [P2 总结](reports/P2-总结.md)，本次界面调整见 [UI-001](reports/UI-001-M3E邮箱与直接阅读.md)。
