## 产品和技术限制

- 不内嵌浏览器；应用内是简化阅读，复杂邮件通过安全浏览器副本查看，不承诺完全保真。
- 中文斜体因字体缺字形仍有缺口；系统富文本剪贴板不保留外部格式。列表/引用等受控结构不等于完整所见即所得编辑器。采用有界编辑模型，不增加字体/编辑器替换工程。
- `In-Reply-To` / `References` 回复线程头仍未接入；无会话聚合，不承诺通用移动/删除撤销。
- 附件默认不提前获取，取消后重试从头下载；结构异常时只有核实整封≤8MiB才允许有提示的完整MIME回退。
- 草稿上传响应未知时先核验，不盲重放；不能确认归属或安全删除时保留旧版本。通用IMAP没有原子版本替换，不承诺自动合并。
- 缓存预算针对可管理对象，不是数据库/备份/索引/匿名下载等总磁盘硬上限；受保护内容超预算只提示。
- 通知尽力且至多一次尝试，崩溃可漏一次提醒，不重放未知D-Bus调用；通知服务成功不等于用户实际看见。
- 默认遵循系统省电策略；240Hz显示器、HUD的1/FRAME均不能直接证明240fps呈现。
- 尚未实测的缩放/跨屏、休眠与网络/电源恢复、非空闲峰值、第二真实账号/独立客户端、真实磁盘满及持续使用，统一见 [项目状态](项目状态.md)，不另建过期待办副本。
- 数据按XDG私有目录和权限保存，不宣称整库加密；凭据仅Secret Service，无明文回退。schema19 / IPC v2前后台必须配套更新，升级先保存并退出。
- OAuth未纳入当前交付；未选定项目许可证，公开发布资格仍待P5处理。
