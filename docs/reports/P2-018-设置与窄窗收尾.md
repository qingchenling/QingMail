# P2-018 · 设置、窄窗与字段错误定位（E 二轮）

> 本轮继续 E 项；最新进度以 [P2 当前状态与剩余工作](../P2-当前状态与剩余工作.md) 为准。

- 日期：2026-11-16
- 状态：设置持久化、窄窗返回/位置记忆、字段错误定位已实现；128 个 Rust 测试与构建门禁通过；列表/阅读一体化仍未完成。

## 1. 本轮范围

1. **设置**：主题、阅读字号、列表密度、减少动态；保存到 XDG 配置目录并立即生效。
2. **窄窗**：列表与详情二选一，提供“返回列表”；按文件夹记忆分页游标与选中邮件。
3. **字段错误定位**：发送前本地校验收件人/抄送/密送与主题，错误显示在对应字段下，并在状态栏提示修正。

## 2. 实现

### 2.1 设置

- 新增 [settings.rs](../../crates/mail-ui/src/settings.rs)：`Preferences { dark, reader_font, compact, reduce_motion }`，读取/写入 `XDG_CONFIG_HOME/qingmail/settings.txt`（临时文件 + rename；失败不保留半成品）。
- 启动时由 `settings::init` 应用主题，取代固定浅色初始化；设置窗口可从邮件主界面“设置”进入，窗口经 `Lifecycle` 复用。
- 主题切换立即重新初始化组件主题并刷新所有窗口；`--home-demo` 的 P0 主题动画也读取该设置。
- 阅读字号：新阅读窗口使用设置值；阅读窗口“字号 ±”同时持久化。
- 列表密度：邮箱列表行高与垂直内边距在紧凑/舒适间切换。
- 减少动态：开启后 P0 首页主题切换直接生效、不排队帧过渡；产品窗口本身没有持续动画。

### 2.2 窄窗与位置记忆

- 宽度 < 1050px 时：点击邮件进入详情视图，显示“返回列表”；不再把列表和详情上下挤在一起。
- 每个文件夹记忆 `(选中邮件 UID, 分页游标)`；切换文件夹时保存当前状态，返回时恢复选中项与分页位置；搜索清除仍恢复原位置。
- 宽窗保留列表 + 360px 详情布局；分隔线拖拽调整本轮未实现。

### 2.3 字段错误定位

- 发送前在 UI 本地校验：地址必须为单个 mailbox（一个 `@`、无空白/控制字符/`<>,;`）、总数至少一个、主题长度与控制字符；通过后才进入存储层发送检查。
- 错误显示在对应收件人/抄送/密送/主题字段下方，状态栏提示“请修正标红的字段”；编辑该字段会清除错误。
- 存储层的发送前校验仍是最终门槛，UI 校验不替代它。

## 4. 限制与剩余 E 项

- 列表与阅读仍是“详情面板 + 独立阅读窗口”，未完全并入同一主窗口；宽窗分隔线不可拖动。
- 主题只提供浅色/深色（跟随系统未做）；设置文件损坏时回退默认，不提示。

- 减少动态只影响 P0 主题过渡；产品窗口没有持续动画可关闭。
