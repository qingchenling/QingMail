# 默认发件箱保存与邮件图片设置

日期：2026-11-19。基于当前1.0.1后续源码，未更新发行包。

## 实现

- 设置名称改为“发送后保存到发件箱”，默认开启。schema23顺序迁移一次性开启既有偏好，并更新偏好版本；之后手动关闭可持久保存。新安装默认开启，历史schema20迁移保持原样。
- 已确认发送任务继续使用冻结策略；不会补存历史记录、再次发送或因改设置重发。发送完成后的副本保存沿用现有流程。
- “外观与阅读”新增“自动加载邮件内图片”，默认开启，保存到前台settings.txt；旧配置缺少此字段时使用开启默认值。关闭后保留单封邮件的手动加载入口，已显示的图片不追溯卸载。
- 普通邮件阅读器每封自动尝试一次，复用后台RemoteImages与受控资源传输；重绘不重复请求，失败及部分失败允许手动重试。合成安全验证样本不会自动访问远程服务器。
- 继续验证远程地址、重定向、图片类型、大小及解码限制；私有网络和主动内容仍被阻止。CID流程与附件按需下载不变。
