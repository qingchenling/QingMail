# 1.0.0 交付与整理

日期：2026-11-19。

## 版本与安装包

- 工作区七个 crate 统一为1.0.0，锁文件同步更新；保留依赖锁定、schema19 与 IPC v2。
- Arch 包为 `qingmail-1.0.0-1-x86_64.pkg.tar.zst`。版本从 Cargo.toml 读取，替换 PKGBUILD 模板，不再在打包工具中维护第二份版本号。
- 包含配套 UI/daemon、桌面入口、图标、安装说明、发行说明和逐文件摘要 BUILD-INFO。交付目录保留安装包、源码包、PKGBUILD、.SRCINFO、BUILD-INFO.json 和 SHA256SUMS，不保留解包/安装暂存目录。
- 主窗口版本显示移除 P4 preview 标识。1.0.0 为用户指定版本；项目许可证状态、实际验证边界和后续公开分发准备如实保留，不执行安装、上传、签名或 Git 标签发布。

## 整理范围

- 将8份逐轮界面说明合并到 `docs/发行说明.md`，更新 README、当前状态、主基线、模块地图、开发验证及安装文档，移除过期0.1.x安装指令和“旧包未包含本轮改动”的当前说明。
- 保留ADR、设计规格、通知/生命周期/性能/打包技术报告和关键证据；保留失败性能采样，不把历史报告中的版本号改成1.0.0。
- 保留全部源码、数据库迁移、合成MIME样本及可复用验证工具；不以“清理”为由删除安全检查或隔离探针。
- 清理旧安装包、设计预览、临时验收目录、日志、Python缓存及Cargo中间缓存。保留当前版本发布二进制与1.0.0交付文件；下次开发构建会重建编译缓存。
- 用户XDG目录、账号、密码、草稿、邮件和自启动配置不属于本次清理范围；已有工作区功能改动随源码快照打包，BUILD-INFO 如实记录工作区状态。

- `python3 tools/build_arch_package.py --output dist/arch-1.0.0` 通过；makepkg完成构建、桌面文件校验、版本检查和打包。包约50.07MiB，输出 `QingMail 1.0.0 (IPC v2)`。
- 七个crate、锁文件与包模板版本一致；164个源码快照文件摘要、安装包及源码SHA256核对通过；文档相对链接及全部Python维护脚本语法检查通过。见 [发布检查](evidence/1.0.0-release-checks.json)。
- 安装0.1.2→升级1.0.0→卸载的隔离pacman事务通过，配套二进制/动态库/桌面入口/图标检查及用户文件哨兵保留通过。见 [包事务](evidence/1.0.0-package-transactions.json)。不修改主机包数据库，跳过依赖求解及钩子，不宣称干净系统或数据库迁移复验。
