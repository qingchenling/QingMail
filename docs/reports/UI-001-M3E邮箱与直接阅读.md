# UI-001 · M3E 邮箱、选信直接阅读与启动同步

日期：2026-11-17。P2 完成状态来自操作者本次会话的明确确认；本轮是既有邮箱的交互和视觉调整，不扩展 P3。

## 1. 样图分析与实现

概念样图 `qingmail-mailbox-redesign-v1.png` 的核心是三栏层级：淡紫直角文件夹树、紧凑邮件列表、以正文为主的阅读区。主操作“写邮件”突出，搜索在顶栏，列表行显示发件人/时间/主题；回复、归档、删除固定在阅读工具栏，维护操作归入菜单。

实现采用锁定的 gpui-kit-material 0.1.4 原生组件、Material Symbols 和语义颜色角色；明暗主题共用布局。侧栏与树行直角，收件箱显示中文且优先排列；宽窗列表/正文分隔线可拖动，窄窗在列表与正文之间返回。移除 UID、UIDVALIDITY 等主界面调试信息，筛选字段按需展开。未虚构摘要、未读数量或多账号能力。

- `mailbox.rs` 保留业务状态；`mailbox_view.rs` 集中邮箱布局。
- `ui.rs` 复用图标、工具按钮、次要按钮与文件夹显示名。
- `reader.rs` 仍是唯一正文渲染入口；内嵌模式省去独立窗口标题与重复回复栏，保留受控简化阅读、纯文本/字号、CID、附件、单封远程图片授权与安全浏览器副本。
- 发送、回复草稿、归档/删除和标记继续调用原有路径；删除仍需确认，失败保留缓存。

## 2. 业务调整

1. 移除“打开正文 / 缓存”和搜索结果的二次打开按钮；鼠标选择、列表方向键及搜索结果直接加载 Reader。缓存优先；缺缓存才按现有路径下载完整 MIME（≤8MiB，不改变远端已读状态）。
2. 正文使用独立加载状态，不锁住列表选信；同时最多一个正文任务，快速切换合并为最后选择。完成时核对账号/文件夹/UIDVALIDITY/UID，旧结果可留在缓存但不能覆盖当前正文。文件夹切换、分页、清除搜索会使旧选择失效；恢复选中 UID 时自动恢复阅读。
3. 复用 SyncEngine，在每个新进程启动时立即执行一次同步；首轮先刷新服务器目录，按可选目录同步，包括从未打开过、尚无本地 UIDVALIDITY 的文件夹。修正旧逻辑只取前四个已缓存文件夹的问题；之后保留60秒轮询和120/300/900秒失败退避。单实例转发/重开窗口不重复创建同步线程。
4. 每次目录/文件夹发布递增修订号；邮箱窗口每3秒检查并静默重读本地缓存。刷新期间保留用户最新选择。网络失败仍可离线阅读。
5. 合成探针显式暂停自动收信并隔离数据、配置、缓存目录；正常运行不依靠隔离环境变量禁用网络。

## 4. 保留限制

单账号、完整 MIME 下载上限、回复线程头、中文斜体字形、主题不跟随系统等既有限制继续记录。本轮未增加多账号/IPC/离线操作队列；未用新阅读或同步管线替换已有能力。正文下载在途时，后续选择合并等待该任务结束，随后加载最后选中的邮件。
