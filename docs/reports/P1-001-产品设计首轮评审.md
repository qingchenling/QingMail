[交互预览源](../design/p1-preview.html) 是评审用界面片段，使用合成数据，不接入账号、不发送邮件；不是产品 WebView。可在当前对话展开查看。独立预览可使用 Codex visualize 的 render.py 包装此片段，不将包装器作为产品依赖。

预览可操作：页面切换、选邮件、窄窗返回、明暗切换、纯文本标识/字号、单封资源授权提示、草稿文字跨页保留、发送六状态选择、不确定重新发送确认、只重试副本、账号连接/密钥库失败模拟和本地搜索。附件、格式、浏览器、删除、后台等按钮仅展示行为说明；非真实操作。设置部分控件仅示意。没有以这些模拟替代原生功能验收。

## 验证与限制

- 预览脚本通过 Node 语法检查；资源内联，无网络请求代码；密码字段禁用，避免误填真实凭据。
- fmt/check/test/clippy 全部通过；21 个 Rust 测试通过。保留既有 5 条 stub manifest 未用依赖提示，无 Rust 实现修改，也无依赖变更。
- 本轮浏览器检查接口返回“Local browser access is unavailable for this chat”，未能视觉验收或运行浏览器交互回归；不可声称布局和明暗对比度实测通过。
- GPUI 原生响应布局、可访问性、快捷键冲突、100/125/150/200% 缩放和原生编辑器缺口仍须后续实现与实测。

## 用户评审清单

1. 阅读：导航/列表/正文密度、简化阅读/纯文本、远程资源和浏览器入口是否清楚。
2. 写信：字段与工具位置、保存状态、离线不自动发送是否符合预期。
3. 异常：结果不确定明确重发确认、已发副本失败只存副本是否易理解。
4. 窄窗：进入阅读、返回原列表、导航入口是否自然。
5. 账号、搜索、设置和快捷键是否有需要调整的习惯。

用户确认后记录修改和验收，再决定 P1 退出；不在本轮擅自开始真实账号/网络发送实现。
