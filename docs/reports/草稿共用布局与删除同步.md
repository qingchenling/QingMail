# 草稿共用布局、发送副本开关与删除同步

日期：2026-11-19。范围为用户提出的三项调整；沿用锁定依赖及现有模块，没有新增独立窗口或重写邮件业务。源码升级为 schema20 / IPC v3，现有1.0.0 Arch包未重新生成。

## 实现

- `Mailbox` 的邮件页统一承担顶栏、列宽、拖动分隔线、窄窗与底栏；Drafts只提供中间草稿列表和右侧编辑内容。删除Composer原有重复顶栏/布局/拖动代码，去掉草稿页独立入场动画。保留普通写信与阅读动效，草稿状态仍仅“已同步 / 本地 / 同步冲突”。
- 设置增加“邮件发送 → 发送后保存副本”，默认关闭，后台持久化；新发送任务和明确重发时冻结策略。关闭时SMTP接受后直接Sent，开启时仍走既有CopyPending与副本查重/保存流程。已确认旧任务迁移后继续原策略；关闭开关不取消旧任务的副本保存，不允许重发。无副本的成功任务不再误写“已保存副本”。服务商可能自行保存副本。
- SMTP明确接受后，在同一存储事务中结束发送任务、删除任务对应的本地草稿版本，并为其已关联的服务器草稿原件排入定向垃圾箱操作；缺少有效Trash或UIDVALIDITY已变化时保留服务器原件。失败或结果不确定时保留草稿。编辑器关闭后，界面切到发件箱并打开不可变的本地发送快照；发送副本开关关闭时不调用IMAP，也不依赖服务器副本存在。
- 底栏同步图标常驻；没有待处理队列时，点击后的浮层为空，不显示账号收信状态或零值摘要。有操作、草稿或发送任务时才显示未完成项；浮层宽度、行密度、最大高度和每类展示数量均已收紧。
- 草稿列表检测到同步冲突或上传结果待确认时，在标题栏显示“处理草稿同步冲突”入口，直达既有冲突面板，可查看两侧内容并选择保留两份、本地或远端版本。
- 普通邮件删除通过持久队列同步移至该账号垃圾箱。修复垃圾箱必须已打开/同步索引才能删除的限制，冻结账号目录中的目标名称，不伪造目标UIDVALIDITY。
- 用户删除草稿同事务排队所有已明确关联的服务器版本并删除本地编辑副本；纯本地草稿无需远端任务。保存失败、身份变化、未决上传或冲突保留草稿。保留原始恢复证据、转换删除标记和冻结发送快照，扫描不复活同一副本。内部损坏草稿恢复入口仍为本地discard。
- 垃圾箱再次删除需明确确认；先确认支持UIDPLUS/IMAP4rev2，再只对指定UID执行STORE/UID EXPUNGE，不执行全局EXPUNGE。不支持时提示到网页邮箱处理。移动响应丢失保持不确定，不盲目重放；永久删除的只读核对只可确认精确旧UID已不存在。
- 前后台协议v3在写操作前拒绝旧v2；schema20顺序迁移前备份，保留旧发送任务策略与其他数据。迁移夹具相应还原旧字段，既有历史报告不改写。决策见 [ADR-0009](../adr/0009-删除同步与可选发送副本.md)。

## 验证

执行相关部分，未运行全工作区测试：

- `mail-storage`：outbox、operations、server_drafts、desktop；覆盖默认关闭、冻结策略、schema19迁移、丢响应去重、离线恢复、同UID跨账号隔离、删除写盘失败回滚、原件保护及未同步目标。自启动迁移夹具另做定向复核。
- `mail-daemon`：sending、storage::rpc；包括关闭副本后不会调用IMAP、旧版拒写、删除响应丢失后只返回原结果，以及原有禁止自动重发场景。
- `mail-protocol`：严格消息、版本、身份与资源边界；`mail-service::actions`：本机受控TLS服务器验证MOVE/回退、精确UID、UIDVALIDITY检查及安全永久删除。不读真实凭据，不收发或删除真实邮件。
- `mail-ui::send_labels`：无副本的Sent不伪称已保存。
- 定向生命周期验证：服务器草稿清理、成功发送删除精确本地版本并保留发送快照、失败/结果不确定保留草稿均通过；workspace all-targets check通过。未运行全量测试。
- 底栏浮层调整通过 `cargo check -p mail-ui --locked` 与 fmt 检查；未运行全量测试。
- 草稿冲突入口通过 `cargo check -p mail-ui --locked`，草稿同步状态定向测试通过。
- 原生草稿探针通过：空态不新建、脏稿切换先保存、关闭/重开、删除后选择下一份与末份空态、回收件箱、仅一个窗口，以及底栏同步状态自动刷新。证据：[JSON](evidence/post-1.0.0-drafts-shared-layout.json)、[日志](evidence/post-1.0.0-drafts-shared-layout.log)。
- 普通写信原生探针通过：格式/历史、IME关闭保护、发送预览取消、多个草稿、窄窗、保存失败保留、退出刷新。发送任务为0。证据：[JSON](evidence/post-1.0.0-compose-shared-layout.json)、[日志](evidence/post-1.0.0-compose-shared-layout.log)。
- fmt / workspace all-targets check / clippy `-D warnings`通过；配套debug前后台构建通过。依赖锁定不变。

## 边界

原生探针验证控件与生命周期，不替代操作者视觉和真实鼠标/IME验收。真实服务商删除、Trash兼容和实际SMTP发送不在本轮执行；真实邮箱中产生的副本行为可能由服务商决定。现有1.0.0包及其源码快照保持原内容，需要后续明确重新打包。切换源码测试前先保存退出旧前后台，不能混用新前台与旧后台；数据库升级后回退需按既有说明恢复完整备份。
