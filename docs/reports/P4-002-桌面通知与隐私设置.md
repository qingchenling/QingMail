# P4-002 桌面通知与隐私设置

> 本篇保留当轮实现和验证事实；当前功能状态与尚未验收范围统一见 [项目状态](../项目状态.md)。旧的下一轮安排不再作为开发待办。

日期：2026-11-18。状态：实现及相关自动测试通过；真实桌面可见性/点击与集中 GUI 验收留 P4-006。本轮未访问真实账号或发送 SMTP，未运行工作区全量测试。

## 实现

- `mail-storage/desktop.rs` 与 schema18：收件箱索引、通知基线和临时候选同事务提交。首次同步、历史加载及 UIDVALIDITY 重建只建基线；重复批次、旧 UID 改未读不再提醒。临时候选记录到达时确为未读的 UID，防止“到达时已读、随后改未读”误报；发送前通过现有本地覆盖层过滤已读/移动/删除。候选不复制头部/正文，发送或抑制后清理，不形成永久通知历史。
- 每账号从首个候选起合并2秒，通知尝试至少间隔10秒；取准确数量与一个定位身份，摘要打开所属账号收件箱。持久候选在外部调用前消费；响应失败或丢失不会自动再提示，普通重启保留去重基线。
- `mail-daemon/notifications.rs`：复用现有 zbus 会话总线，标准 Notify、GetCapabilities、动作及关闭信号。无服务、权限失败、超时分别给出状态；服务所有者变化自动更新状态、废弃旧动作，无空闲高频探测。存储成功提交后唤醒，只有待合并/限流期限到达时再处理。
- 默认仅账号及数量。发件人/主题和预览分别显式开启；所有内容有界、转义。预览只读取已缓存完整 MIME 或正文分段，复用既有解析清理，不触发正文、CID、附件或远程图片下载。
- 动作校验当前通知服务的唯一总线身份及本地随机 token 映射；全局最多256条、24小时过期，关闭/服务更换/后台重启失效。单槽最新点击意图防止无界排队；复用会话激活与同目录前台启动，启动中合并，超时/失败可重试。
- 邮件窗口复用账号目录/缓存、现有阅读器和分页，按完整账号/文件夹/epoch/UID定位；失效或已移除时打开窗口并提示，不复用错误 UID，不触碰编辑器或发送任务。
- 设置页新增 M3E 通知与隐私选项、服务状态、刷新及错误反馈，内容可滚动。桌面偏好归后台，不与前台外观文件并发写入；修订号冲突拒绝覆盖，响应丢失查询原写请求而不重放。

## 协议与迁移

IPC 升级为 v2，详见 [ADR-0008](../adr/0008-桌面通知协议v2与持久去重.md)。严格激活枚举扩展无法保证旧前台兼容，故在任何写入前拒绝主版本不匹配；Hello 同时校验 DesktopSettings/UpdateDesktopSettings/OpenMail。传输上限与资源通道不变。

schema17→18 保留账号、凭据引用、草稿、缓存和发送任务，迁移前创建私有备份。旧迁移测试的降级夹具同步移除新增表，避免把 schema18 表残留误当旧库；一个历史测试的硬编码17改为当前版本常量。生产同步/阅读/发送业务不重写，依赖锁版本不变。

升级操作：先在旧版“保存并退出”，再配套更新 `mail-ui` 与 `mail-daemon`；旧 P3 包不含通知且不能读 schema18。本轮未重新制作 release 测试包，也未迁移真实用户数据。自启动、Arch 包和性能预算仍属于后续迭代。

## 明确边界

- 桌面通知服务是否实际显示、系统勿扰/锁屏的展示由系统决定；调用成功不等于用户看见。未实测 Hyprland 通知弹窗和新设置视觉状态，不以私有服务测试冒充 GUI 验收。
- 至多一次尝试允许消费后崩溃漏一次提醒；不影响缓存邮件。会话总线启动即不可连接时继续收信；需重启后台重新连接，已有总线上的通知服务消失/重现则自动检测。
- 精确定位先查本地完整身份；邮件删除/账号移除显示提示。未缓存预览直接省略；阅读仍沿用按需资源流程。非“actions”服务只显示提醒。
- 未扩展OAuth、自启动、通知规则/声音配置、通知中心、自动发送或缓存预算。自启动现已交付，见自启动报告。
