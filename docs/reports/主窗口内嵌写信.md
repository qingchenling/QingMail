# 主窗口内嵌写信

日期：2026-11-18。按用户确认的深色 M3E 预览实现；本轮只整合写信工作区，不增加邮件业务、数据库迁移或 IPC 版本。

## 已实现

- 新建、回复、回复全部、转发和服务器草稿入口统一进入主窗口右侧，与阅读区互斥。再次点击同账号写信复用当前草稿；切换账号或打开另一份文档先保存当前内容。
- 顶部图标工具栏提供粗体、斜体、链接、列表、引用、撤销、重做、附件和更多操作；窄列将列表/引用放入更多菜单。图标保留说明、选中和禁用状态。
- 下方依次为收件人、主题和正文；抄送/密送按需展开，非编辑中的地址显示可移除标签，点击编辑图标重新输入。正文取消并排 HTML 预览。
- 附件位于正文下方；底部显示发件账号、草稿菜单和保存状态。账号菜单明确为打开该账号的草稿，不静默迁移现有草稿归属。
- 关闭写信或点击邮件先保存，再返回阅读；加载、IME 候选词、附件导入或保存失败时保留工作区。保存失败立即恢复输入；重试成功后可以继续编辑并保存。
- 主窗口关闭仍协调保存后退出 GPUI，daemon 保留。发送继续使用已有检查与明确确认、持久任务和禁止自动重发规则。
- 移除独立写信窗口的创建、标题、窗口关闭处理、多窗口登记/复用及旧展示布局；复用 Composer 文档、历史、自动保存、字段、附件和发送实现。生命周期只登记一个由主窗口持有的编辑器保存参与者。
- 更新旧生命周期/进程拆分探针的单窗口预期；读信和写信脚本分开运行，避免争用同一右侧工作区。保留历史验收证据，不修改其当时结论。

## 边界

上述 GUI 探针操作原生输入协议与实体，不冒充真实鼠标或真实中文输入法验收；最终视觉、真实输入法和缩放组合仍由操作者确认。本轮不访问真实账号、密钥库或发送邮件，不代表 P4-006 整阶段验收完成。已有中文斜体等限制不变。

本轮构建了发布二进制，未重打先前的 Arch 预览包；旧包不包含本轮界面变化。
