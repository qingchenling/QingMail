# P3-002c：账号安全提交与凭据版本

日期：2026-11-17。基线：9c6dbf6。状态：本轮实现与自动化验证完成；P3-002 进程拆分尚未完成。

## 实际交付

- schema9→10 增加正式凭据版本引用，迁移前备份，保留旧账号键、草稿及发送任务。兼容历史账号标识，不修改系统密钥库内容。
- 连接检查令牌绑定目标账号、原配置及活动凭据版本。提交前与提交事务内均校验基线；另一次更新即使配置相同，也不能用旧检查结果覆盖新凭据。
- CommitAccount 使用独立单线程、最多2个等待任务。持久取得请求执行权后返回 InProgress；前台断连不取消已接受的工作，有序关闭完成已接受提交。
- 新凭据保存到独立随机正式键，不覆盖旧键。账号配置、活动引用与成功请求结果同一数据库事务提交；结果写入失败也回滚账号变更。
- 同请求同参数返回原结果，变更参数拒绝；重启后的未完成请求为 Uncertain，不消费检查令牌、不再次写密钥库。查询结果而非自动重放提交；未完成日志且无活动任务时也显示结果不确定。
- 密钥库锁定、写入超时、数据库失败均保留旧凭据及配置。只有数据库确认新键无引用才清理候选键；未知结果保留。成功后尽力移除临时项，清理失败不撤销保存结果。
- 现有进程内账号更新也改用版本切换；同步、邮箱读取、发送协调与发送任务页读取服务器副本均使用活动凭据。显式移除本地账号时按已记录版本清理密钥库，不扫描其他项目。
- 协议继续只传引用，无密码字段；未增加 SMTP 发送能力，也未改变禁止自动重发规则。
