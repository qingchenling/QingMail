## 1. 本轮行为

主窗口增加“添加邮箱”，打开独立原生账号窗口。提供账号名、邮箱地址、IMAP/SMTP 主机、端口、用户名与各自密码，以及 TLS / 必须 STARTTLS 选择。端口不随加密按钮静默改写；用户按服务商配置填写。暂不提供 OAuth、明文连接或跳过证书验证。

“检查连接”在后台分别验证 IMAP 与 SMTP，显示各自固定分类结果。两项均通过后才能“保存账号”。配置变化即丢弃已检查凭据并作废结果，保存时再核对当前配置与检查快照；密码输入在检查开始后清空，失败/修改后需重新输入。密码字段遮蔽并使用 Material Password 类型。检查期间禁用表单；关闭窗口丢弃结果，不触发账号保存。保存必须由明确按钮触发，保存期间阻止关窗，应用退出等待已接受的账号保存请求。

左侧账号列表可展开，容器最左侧保持直角。已保存账号明确显示“尚未同步文件夹与邮件”。检查发现的文件夹在右侧只读列出，保留原始协议标识，并将 modified UTF-7 解码为中文显示。没有用收件箱/草稿占位冒充真实文件夹同步。账号配置支持重开枚举；当前 P2 接入入口仅允许一个远程账号，多账号能力仍留在 P3。存储层原有多账号隔离测试保留。

新增 `--accounts` 单实例命令，已有进程时直接重开/激活账号窗；主窗口也可重复打开并复用现有账号窗。原有编辑、阅读、托盘和关闭重开流程保留。

## 2. 凭据与持久化边界

mail-service 提供 CredentialVault 与 Secret Service 实现，仅使用 default collection，使用 DH 加密会话；系统密钥库锁定时不自动解锁，提示用户在系统解锁后重试。以 application/account/purpose 三项属性定位凭据。一个密钥项包含 IMAP 与 SMTP 两份密码，避免只保存半套；创建后读取并核对内容，确认后才允许插入 SQLite 非秘密账号配置。

密钥库每项操作有 15 秒总等待上限，D-Bus 单次方法超时 5 秒。异步等待到期会取消本地 future，不把超时当远端回滚。密钥库失败/锁定/不可用时不插入账号，不回退文件。保存失败或超时可能留下凭据项，会明确提示结果未确认。若账号插入失败，仅在查询确认远程账号不存在时删除该 ID 的凭据；提交结果未知时保留凭据并提示刷新。进程在密钥保存后、账号写入前崩溃仍可能留下孤立项，本轮没有启动扫描清理或跨 D-Bus/SQLite 原子事务。

账号操作经既有 storage 工作线程，SQLite 不进入 UI listener。密码不加入 SQLite、日志或命令行；自有秘密字符串、编码缓冲和 IMAP LOGIN 命令使用 zeroize，Credentials 不实现 Debug/Clone。框架输入历史、lettre/系统库及 D-Bus 内部副本不保证全部清零，不能据此宣称进程内不存在残留副本。

## 3. 协议检查与库版本

IMAP 使用 native-tls 的系统信任链与主机名验证，最低 TLS 1.2。STARTTLS 前只交换有界 greeting/升级命令，升级失败直接停止，不发送用户名或密码。TLS 后发送转义的 LOGIN、只读 LIST，最后尽力 LOGOUT。匹配响应 tag 时返回可处理错误，不对服务器输入使用断言。当前仅支持密码 LOGIN，不提供 SASL/OAuth、PREAUTH 会话接管、邮件 FETCH、UIDVALIDITY 同步或写操作。

IMAP 响应由稳定版 imap-proto 解析，限制每阶段 1 MiB 读取、4096 项响应、2048 个文件夹；STARTTLS 单行 8192 字节/最多 64 行。读取阶段有 20 秒软截止，单次 socket 读写 5 秒；DNS 使用系统解析器，没有独立取消期限，因此不能宣称整个账号检查严格在固定秒数内结束。SMTP 使用 lettre 的 required STARTTLS 或隐式 TLS，默认校验证书与主机名，5 秒超时；test_connection 进行 EHLO、认证、NOOP，不调用 MAIL FROM/RCPT TO/DATA。SMTP 未增加应用层累计响应字节上限，后续协议工作需补齐整体资源预算。

错误仅展示固定中文分类；不显示服务器原始认证响应或底层错误链。对 lettre 嵌套的 TLS/超时原因按错误类型追溯，避免证书失败误显示为普通连接失败。SMTP DNS 与部分连接失败仍合并显示，尚未细分所有服务商错误码。

锁定新增直接库：secret-service 5.1.0、imap-proto 0.17.0、lettre 0.11.23、native-tls 0.2.18、zeroize 1.9.1；使用已有 async-io 2.6.0、futures-lite 2.6.1、nom 8.0.0 与 base64 0.22.1。测试证书由仅开发依赖 openssl 0.10.82 动态生成。Linux native-tls 依赖系统 OpenSSL/CA，打包时需声明。本轮没有升级 GPUI Kit 0.9.1 / Material 0.1.4 / gpui-pre 0.3.12。最终锁文件增加 10 个包，旧 IMAP 客户端与其未来兼容警告不在最终依赖图中。
