# P3-002e：后台会话、资源通道与远端存储适配

日期：2026-11-17。属于 P3-002 的实现增量，**不代表单账号进程拆分已完成**。正式 mail-ui 入口仍使用原进程内后台；本轮没有切换正式数据库所有者，也没有读取真实账号或发送邮件。

## 实现

- daemon 接入 AttachUi、UiHeartbeat、DetachUi、Activate、PrepareShutdown、FinishShutdown。单前台令牌租约15秒；同令牌重连续租，第二前台只获得“已有前台”的结果并请求激活，不泄露现有令牌。激活带独立递增序号，确认后清除。
- 两阶段退出：有活动前台先请求保存；保存失败取消退出并保留前台，成功确认才停止后台。租约过期不等于保存成功，原退出请求取消；活动账号提交或发送任务期间拒绝立即退出。无前台时沿用显式退出入口。正式窗口保存、心跳和托盘尚未接入这些接口。
- Snapshot 返回 epoch、统一版本、账号及后台状态；读取期间观测到版本变化时重取。Events 为256项有界失效日志，落后超过保留窗口或超前版本必须重新获取快照。账号/草稿/发送/资源变动保守触发相关失效，自动同步触发邮件失效；不宣称已有离线队列或草稿冲突。
- SyncEngine 增加合并收信请求及显式暂停接口。请求在同一同步线程串行执行，轮询期间的多次请求合并为下一次收信；手动收信可在自动暂停时执行。隔离模式不能通过恢复/切换暂停来开启网络。停止时唤醒等待线程。
- 资源只接受随机受控ID，通过独立连接的 NDJSON 头和后续二进制数据传输，单块最多64KiB；沿用同用户/权限检查、帧上限和绝对读写期限。资源池最多128项、预留总量64MiB、空闲10分钟失效；上传仍遵守25MiB限制。读端核对ID、偏移、总量、终止状态及调用方指定的总量上限。
- CreateUpload/WriteResource/FinishUpload/CancelResource：偏移必须连续，越界和未完整分块不修改已接收内容；不完整上传不能导入附件。完成确认先取得持久请求执行权，再复用 Store.import_attachment；已完成的同ID请求返回同一附件，中断请求只允许查证。不接收客户端文件路径，不新增无限大小 MIME 下载。
- SelectedDraftBody 将既有受控草稿JSON放在资源通道，而非控制帧中。资源类型为 application/vnd.qingmail.draft+json。
- daemon 发送接口复用既有 SendCoordinator：ReviewSend 返回5分钟有效、最多16个的单次预览令牌，绑定具体草稿版本；ConfirmSend/Resend/RetryCopy 先持久登记请求，独立线程执行并保存结果，同时仅一个发送/副本任务。确认响应丢失后查询原ID，进程重启不重放未完成确认。隔离 daemon 不开放任何发送/密钥库执行能力。
- StorageWorker.connect 提供**尚未用于正式启动的**远端适配器：复用编辑器现有异步有界队列，草稿、附件元信息、缓存查询及发送记录映射类型化IPC；该适配器不打开 SQLite。所选附件仅在前台按既有 NOFOLLOW/NONBLOCK/普通文件/大小规则读取，再分块上传，原本地入口共用同一文件检查。写确认丢失先查询，不重发写请求。SendCoordinator 也具备远端令牌分支，前台只确认一次、随后只查询结果。

## 验证

fmt --check、check --workspace --locked、test --workspace --locked、clippy --workspace --all-targets --locked -- -D warnings 全通过，**174个 Rust 测试**（原163个，本轮新增11个）。本地 socket/模拟服务器测试需要沙箱外运行，其余仍为隔离目录与合成数据。

新增覆盖：

1. 租约续期、第二实例激活/确认、错误令牌、前台崩溃及过期退出取消。
2. 保存失败取消退出、关闭前台后后台仍在、重新连接恢复、保存成功后退出。
3. 事件溢出/超前版本触发重取、重复版本观察合并。
4. 上传不完整/错位/越界拒绝，读取边界、资源过期/取消和容量限制。
5. 真实独立进程上的多块二进制草稿读取、二进制附件上传、重复完成确认返回同一附件。
6. 同一编辑器存储API跨IPC创建/保存草稿、导入附件、关闭适配器后重开恢复；前台源附件删除后后台副本仍可读取。
7. 发送预览无任务副作用、过期/数量/版本限制；失效确认和孤立持久记录均不执行网络或恢复重发。既有发送协调器的假凭据/假传输测试继续通过。
8. 暂停期间显式收信及轮询中的多个请求合并。

没有执行真实 SMTP、真实 Secret Service 交接、正式 GUI 集中 E2E 或原生性能测量。没有把独立进程协议测试算作完整单账号 GUI 验收。
