# P2-015 · 持续收信、历史加载与基本邮件操作

> 历史轮次记录：下文“当前/尚未”均指本轮结束时；最新实现与待办以 [P2 当前状态与剩余工作](../P2-当前状态与剩余工作.md) 为准。

- 日期：2026-11-16
- 状态：实现、126 个 Rust 测试与构建门禁通过；真实账号与原生批量操作未验收。

## 1. 本轮范围

完成 C 项：

1. **基本邮件操作**：已读/未读、星标/取消星标、归档、删除（移到已删除）；批量选择；标记操作可撤销；失败不改本地缓存。
2. **持续收信**：单账号低频轮询（60 秒）、暂停/恢复、失败退避（120/300/900 秒）、目录周期刷新、当前文件夹自动重读。
3. **历史上限**：主动加载最近 90 天之前的邮件，按 UID 游标分批。
4. **远端对账**：完整最近批次缺少的 UID 从缓存删除；90 天之前的缓存不因最近窗口对账而删除；远端标记随批次更新。
5. **附件取舍**：明确记录“整封 MIME 下载”的现状与理由，不把按部分下载写成已完成（见 §4）。

不新增多账号调度、IDLE、CONDSTORE/QRESYNC 或持久离线操作队列（P3）。

## 2. 实现

### 2.1 标记与操作

- schema v7：`folder_messages` 增加 `seen/flagged`；同步 FETCH 增加 `FLAGS`，批次携带每封标记，缓存列表显示未读/星标。
- [actions.rs](../../crates/mail-service/src/actions.rs)：
  - `store_flags`：`SELECT` 核对 UIDVALIDITY 后 `UID STORE ±FLAGS.SILENT`；已读与星标可同批更新。
  - `move_messages`：优先 `UID MOVE`；服务器不支持时退化 `UID COPY` + `\Deleted` + `UID EXPUNGE`，EXPUNGE 未确认时返回 `CopiedOnly`，不谎报彻底移除。
  - 所有操作成功后由 UI 调用存储线程回写缓存；失败只显示原因，不改缓存。
- 目标文件夹：复用 [folders.rs](../../crates/mail-service/src/folders.rs) 的特殊文件夹启发式（上次记录优先、modified UTF-7 解码、可选节点），归档/已删除找不到时拒绝执行，不永久删除。
- 批量：列表逐行复选框、全选本页/清除选择；无勾选时操作当前选中邮件。
- 撤销：标记操作记录原状态，提供“撤销标记”；移动/删除不提供撤销（目标 UID 未建立映射），状态栏明确说明结果。

### 2.2 持续收信

[sync_engine.rs](../../crates/mail-daemon/src/sync_engine.rs) 在单进程内运行独立线程：

- 每 60 秒同步最多 4 个已同步文件夹的最近 90 天批次，每 5 轮刷新一次 LIST 目录。
- 暂停/恢复由原子开关控制；失败按 120/300/900 秒退避，状态文本持续显示最近成功或失败原因。
- 不自动发送、不自动重试邮件操作；与手动同步、发送线程共用存储线程，数据库仍单写者。
- 邮箱窗口每 3 秒刷新状态、约每 15 秒轻量重读当前文件夹缓存，自动收信结果无需手动刷新即可出现。

### 2.3 历史加载与对账

- `sync::history`：`UID SEARCH BEFORE <90天>`，按 UID 游标取最多 200 封，`BatchKind::History` 只追加、不触发对账。
- 存储批次增加 `complete`：只有“无游标且没有更多”的最近批次才删除 90 天内已不存在的缓存；90 天之前的缓存保留。
- 邮箱“加载更早历史（90天前）”按钮；没有结果时标记已耗尽。

## 4. 附件取舍（明确记录）

现状：首次打开邮件仍用 `BODY.PEEK[]` 下载整封 MIME（含内含附件），上限 8 MiB；附件不是按需单独下载。P2 不实现 BODYSTRUCTURE + 按部分获取，理由：

- 阅读链路以“原始 MIME → `mail_content::parse`”为单一安全边界，拆分会引入部分 MIME 拼接、缓存键和附件状态的新一致性问题；
- 单封 8 MiB 上限已经限制了最坏下载量，P2 单账号场景可接受；
- 按部分下载与缓存淘汰、未完成任务保护一起属于 P3 缓存重构，避免在 P2 另造一套附件获取/缓存路径。

这是**明确的产品取舍**，不是“已满足附件主动下载”。集中验收时需要操作者确认接受；若不接受，应单独立项实现按部分下载，而不是把现状写成已完成。

## 5. 限制与下一轮

- IDLE 未实现，本轮选择低频轮询；暂停只在进程内有效。
- 移动/删除无撤销；服务器既不支持 MOVE 也不支持 UID EXPUNGE 时只能报告“已复制并标记删除”。
- 自动收信会周期性读取 Secret Service；密钥库锁定/失效时进入退避，用户仍可手动同步。
- 历史加载按 UID 游标，不保证按日期严格连续；90 天前缓存不参与普通对账。
- C 项功能已落地，真实账号持续收信、批量操作与网络故障恢复仍待集中验收。
