## 4. F 验收方式

1. 使用测试包与隔离数据目录启动。
2. 按 `README-TEST.md` 的五组清单逐项记录通过/失败/条件不足。
3. 真实发信只向操作者自己的测试地址发送；不向第三方投递。
4. 失败项记录步骤、界面提示、是否重复发送/远端数据影响；保留终端日志。
5. 把结果回写本报告或新报告；修复后重跑相关门禁与必要人工项。
