# P3-002d：共享账号命令与前台接入

日期：2026-11-17。基线：f0f669d。状态：本轮实现及自动化验证完成；生产进程拆分与集中 E2E 未完成。

## 实际交付

- 提取 `AccountGateway`，IPC 服务与过渡期前台共享 CheckAccount、AccountCheckStatus、CommitAccount、MutationResult 的同一处理逻辑、基线校验及持久幂等语义，不复制认证/存储/提交业务。
- 正式账号页检查先将输入凭据写入 Secret Service 临时项，清除输入框并释放本地 Credentials，只传随机引用。认证在后台检查线程执行；前台收到成功结果后仅保留检查令牌与非秘密配置，尽力移除临时项。保存只提交令牌与目标账号，不再调用旧 add_account/update_account 路径。
- 工作流具有进程内 AccountGateway 与 Unix Client 两种端点实现。正式应用当前使用前者，共享原有唯一 StorageWorker；本轮没有同时启动第二个 daemon 争用数据库，也没有宣称已通过跨进程验证。
- 提交前在独立前台目录持久保存原请求ID及新增/更新类别：0700目录、0600文件、单写锁、长度/格式校验、文件fsync、原子替换及目录fsync。写入未确认则不提交；书签没有密码、临时项引用、检查令牌或完整命令。复用 mail-storage 的 PrivateDir；没有升级 schema10。
- 响应丢失后只查询原请求；后台执行中有界等待，超时、查询失败、NotFound 或 Uncertain 保留书签。成功或持久失败结果确认后清理书签；清理失败仍保留查询入口。关闭/重开账号窗口及应用重启均恢复待查询状态，不恢复写请求。
- 增加“查询保存结果”与“已核对账号，结束查询”入口。结果待确认时禁用新的检查、编辑和移除；用户可刷新并核对账号后明确结束查询。存在活动后台提交时不能结束查询；结束查询不取消或重放原请求，再修改仍需新的基线检查。
- 全局退出流程等待活动账号提交，避免只凭窗口保存标记判断后台已完成。账号窗口的原保存期间关闭保护继续生效。

## 剩余边界

- 仍是进程内桥接；正式启动器、UI 全量 Unix socket 切换、会话/激活/事件/托盘/协调关闭未完成。隔离 daemon CLI 仍不启用密钥库或邮件网络。
- 账号列表、移除影响统计及移除仍走原内部存储接口；移除中的密钥库访问尚待迁出存储线程。后台临时项启动清理钩子及 Secret Service 跨进程验证待生产接入与集中 E2E。
- 正常请求书签在 XDG 配置目录的 `qingmail/client-requests`，隔离探针在其数据覆盖根对应存储目录下的 `client-requests`。记录损坏不静默忽略、不覆盖；须保留原件核对。它只用于账号提交恢复，不是 IMAP 离线队列或 SMTP 重发许可。
- 网络/资源API、发送预览与持久确认、列表分页仍待迁移；完成进程拆分后再集中验证原有单账号行为，不提前标记 P3-002 完成。
