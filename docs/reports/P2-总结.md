## 3. 关键实现与复用

- 依赖方向：`mail-core ← mail-content / mail-storage ← mail-service ← mail-daemon ← mail-ui`；协议层不依赖 SQLite，UI 不直接开数据库。
- 发送状态机是唯一写入口：`SmtpAttempt` 许可、`CopyPending` 隔离、失败/不确定禁止自动重发（ADR-0005）。
- 冻结快照确定性重建 MIME；预览、SMTP、APPEND 使用同一字节。
- IMAP 认证/响应边界/特殊文件夹/期限复用同一骨架；发送任务、存储线程、阅读组件均复用既有组件，不新造第二套。
- 设置/搜索/状态文案等跨窗口能力集中在 storage、`send_labels`、`settings`；主界面内嵌 Reader，不复制正文渲染。
