- 状态：E 项实现收尾；129 个 Rust 测试与构建门禁通过；原生交互与真实账号转入 F 集中验收。

## 1. 本轮范围

1. **同窗阅读**：正文不再只能打开独立阅读窗口；主窗口宽布局为“列表 + 阅读”双栏，窄布局进入阅读后提供“返回列表”。
2. **分隔线**：宽布局列表/阅读之间的分隔线可拖动，宽度 280–720px。
3. **设置补充**：设置解析增加单元测试（默认值、字号夹取、未知键忽略）。

## 2. 实现

### 2.1 复用阅读组件

- 不新写第二套正文渲染：把 `reader::Reader` 的构造与类型开放到 `mail-ui` 内部，主窗口在阅读某封邮件时创建内嵌 `Reader` 实体并放入详情栏。
- 因此同窗阅读直接复用既有：简化 HTML 文档、纯文本切换、字号、CID 图片、附件另存、远程图片授权、浏览器副本与清理、链接交互。
- 独立阅读窗口仍保留“在独立窗口打开”，用于需要更大空间或对照；两者使用同一 `Reader` 组件。
- 打开正文仍按“缓存优先、缺失时只读下载、成功后解析并记录附件数量”的路径；搜索命中从对应文件夹与 UID 打开。
- 窄布局点击阅读进入详情视图，顶部“返回列表”回到原列表；宽布局忽略该状态。

### 2.2 分隔线与布局

- 宽布局改为左侧固定宽度列表（默认 420px，可拖动调整）+ 右侧自适应阅读栏；分隔线 6px、列调整光标。
- 拖动时按窗口坐标差值更新宽度并夹取 280–720px；松开结束调整。
- 列表仍保留账号文件夹树、搜索、操作栏与分页；阅读栏在内嵌 Reader 上方提供“在独立窗口打开”。

### 2.3 设置测试

- `Preferences::parse` 覆盖默认值、字号 99→28 夹取、未知键忽略、非法字号回退 16。

## 4. E 项完成情况与限制

E 项实现层面完成：本地搜索、默认邮件入口、账号管理/发送任务入口、收件人 chips、Cc/Bcc 折叠、设置持久化、窄窗返回与位置记忆、字段错误定位、同窗阅读与可拖动分隔线。

仍记录的限制：

- 主题只有浅色/深色，不跟随系统；设置文件损坏时静默回退默认。
- 设置只持久化主题/字号/密度/减少动态；窗口尺寸与分隔宽度不持久化。
- 同窗 Reader 仍保留独立窗口的标题栏与工具栏样式，排版需在 F 做原生核对。
- 列表/详情与阅读已同窗，但“阅读顶栏的回复/转发”仍在内嵌 Reader 内；主窗口不额外复制一套操作。
- 原生探针、人工视觉与键盘/焦点核对属于 F 集中验收，不在本轮宣称通过。
