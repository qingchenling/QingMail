# P3-003：多账号与统一收件箱

日期：2026-11-17。基线：P3-002f（`f42f7c8`）。状态：实现与隔离自动测试通过；真实双账号兼容及最终 GUI 集中验收留 P3-007。

## 1. 实现范围

- 移除单远端账号限制，复用既有 Secret Service 临时凭据交接、检查令牌、账号提交及移除流程；更新已有账号时与同步共用账号执行许可，防止旧配置结果覆盖新配置。
- 左侧保留直角账号/文件夹树，各账号及其子目录独立折叠。多账号时显示统一收件箱，按日期、账号、内部邮件 ID 稳定分页，不按 Message-ID 合并。选信直接阅读，启动请求同步。
- 统一列表及跨账号搜索标识账号；阅读、选中、勾选、回复与批操作保留完整 `account/folder/UIDVALIDITY/UID` 定位。刷新后丢弃失效勾选，避免 UID 重用误操作。统一批操作按账号、目录及 epoch 分组，分别显示成功和失败；移动结果不确定时提示核对，不自动重放。
- 本地搜索可选当前文件夹、当前账号、全部本地缓存；范围可见，不发远端搜索。发送任务聚合所有账号并可按账号筛选，任务阅读使用自身账号。
- 账号页提供默认发件账号、逐账号暂停/恢复。普通文件夹新信使用当前账号，统一收件箱使用默认账号，回复使用原邮件账号；编辑器显示发件账号，已存草稿不换归属。不同账号可各自打开编辑窗口，回复全部排除所有已配置自身地址。

## 2. 后台调度与协议

复用 `SyncEngine`、StorageWorker、mail-service IMAP 和现有发送协调器；没有另建同步业务或修改 SMTP 自动恢复规则。

每账号独立工作循环，启动同步近90天索引；INBOX 优先，目录和其他文件夹首次及每5轮刷新。独立暂停、认证错误和120/300/900秒加0～15秒稳定抖动的退避。认证失败等待手动同步或配置变更，单账号失败不终止其他账号。手动请求合并，显式手动同步可在暂停期间运行一次；暂停不强行中止在途操作。

新增 `network_gate`：最多两个主动 IMAP 任务，同账号串行；前台阅读/操作优先，同优先级按到达顺序。同步每目录释放许可，失败依靠 RAII 释放，不长期占住账号。同步在取得许可后重新核对账号版本；移除和已有账号配置提交也使用同一许可。SMTP 串行发送约束保持。

新增只读 IDLE：CAPABILITY 检测、EXAMINE INBOX、IDLE/DONE；EXISTS/EXPUNGE/FETCH 触发索引刷新。不支持或失败回退60秒轮询，周期目录刷新时再探测。当前每账号最多一条 IDLE，静默15秒后丢弃并重建连接，半帧超时也不复用流；不是长期复用连接。IDLE 和账号连接检查独立于两个主动邮件任务，实际服务商长期行为仍需兼容验收。

IPC v1 新增 `AccountOptions`，接入既有 UnifiedInbox、SetDefaultAccount、跨账号 Search 和逐账号 PauseSync；Hello 声明支持能力。DaemonStatus 的 `account_sync` 含逐账号状态，反序列化缺省为空；Snapshot 返回持久默认账号。默认/暂停写入沿用持久幂等请求记录；前台控制调用有5秒结果等待上限，超时不自动重放发送。

## 3. 数据迁移

schema10→11 新增 `account_options`（账号外键、唯一默认账号、暂停标记）。首次账号成为默认；后续账号不会静默抢占默认。删除默认账号时在同一事务内选取剩余账号；无账号则为空。偏好重启后保留，现有账号、凭据引用、草稿、附件和发送任务不重建。

继续使用原有迁移前备份、顺序事务升级及未来版本拒绝；回退测试夹具同时移除新表和触发器，以模拟真实旧版本结构。
