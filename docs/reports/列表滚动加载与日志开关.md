# 列表滚动加载与日志开关

日期：2026-11-18。

## 改动

- 左下角后台诊断日志默认隐藏；设置增加“主窗口诊断日志”开关，即时生效并保存至现有 XDG 配置。旧配置没有该字段时默认关闭；操作结果提示仍保留。
- “写邮件”按钮由 48 降至 42 逻辑像素高，略微缩窄，使用 16 逻辑像素圆角；账号文件夹侧栏外缘仍为直角。
- 删除“返回最新缓存”“下一页缓存”按钮和“本页”标题。虚拟列表显示到末尾附近时追加下一批本地索引，不替换已有列表、不重置选择和滚动句柄。后台仍使用原来的有界查询，未修改存储或 IPC。
- 普通文件夹和统一收件箱均支持追加；按完整账号/文件夹/UIDVALIDITY/UID 身份去重。末批不足时停止查询，整批恰好结束时再通过一次空批次确认；失败保留列表并提供重试，避免自动循环失败请求。
- 同步静默刷新重新读取已加载深度，保留阅读选择和滚动句柄，避免拼回服务器已删除邮件。切换文件夹记住已加载深度，便于恢复原选择。
- 较早服务器索引继续使用已有更多菜单入口；查询90天内较早邮件后也保留已显示列表，90天之前历史仍需明确加载。本轮不改变同步时间范围，不隐式下载正文或附件。

- `cargo test -p mail-ui --locked settings::tests -- --nocapture`：1 项通过，包含旧配置默认隐藏及开关值解析。
