# QingMail 1.0.1

日期：2026-11-19。本版包含此前源码后续改动；前后台使用 IPC v4，数据库从1.0.0的schema19顺序迁移至schema21。必须保存并退出旧前后台后再升级。下方1.0.0发布记录保持原内容。

- 账号页新增 Outlook / Hotmail 与 Microsoft 365 浏览器 OAuth 登录、内置应用 ID、取消与重新授权；后台自动刷新令牌，收发只使用 XOAUTH2。应用 ID 已内置，门户配置与真实兼容待验证，步骤见[接入说明](Outlook邮箱接入.md)。
- Drafts 共用收件箱的顶栏、分栏宽度和底栏；中间为草稿列表，右侧为编辑器，移除独立页面入场动画。
- 设置 → 邮件发送新增“发送后保存副本”，默认关闭。只影响新确认的发送任务；服务商可能自行保存副本。
- 删除普通邮件或已关联的服务器草稿，会同步移到该账号垃圾箱；离线先保存任务。垃圾箱再次删除需确认，且服务器必须支持安全定向清除。
- 上传结果未定、冲突、身份变化或保存失败时保留数据；未完成项仍从右下角同步状态查看。真实邮箱删除未在本轮执行。

安装包为 `qingmail-1.0.1-1-x86_64.pkg.tar.zst`。先保存并退出旧前后台，再执行 `sudo pacman -U /绝对路径/qingmail-1.0.1-1-x86_64.pkg.tar.zst`。本轮只构建与隔离验证，不自动安装或上传。功能实现见[草稿与删除记录](reports/草稿共用布局与删除同步.md)、[OAuth记录](reports/Outlook-OAuth接入.md)，打包结果见[交付记录](reports/1.0.1-构建交付.md)。

# QingMail 1.0.0

日期：2026-11-19。面向 Arch Linux / Hyprland / Wayland 的正式版本号；使用通用 IMAP/SMTP。UI 与 daemon 必须配套更新，数据库 schema19、IPC v2。

## 当前界面与使用方式

- 左侧为多个账号各自的文件夹树，保留直角边缘；多账号可使用统一收件箱。邮件列表向下滚动追加本地缓存，较早服务器索引从更多菜单加载，不再显示分页按钮。
- 点击邮件直接阅读；每次启动应用请求一次合并同步。正文、CID 与附件按需获取，复杂 HTML 使用安全浏览器副本。
- 点击“写邮件”在主窗口右侧编辑，顶部使用格式图标，下方依次为收件人、主题、正文，支持附件、抄送/密送、回复/转发及多草稿。切换或关闭先保存，保存失败保留内容。
- 账号管理和设置从右上角图标进入，替代中间与右侧区域，表单在导航间保留。日志与完整连接检查详情默认隐藏，在设置中开启。
- 点击账号 Drafts 进入三栏草稿工作区：账号树、草稿列表、编辑区。草稿显示“已同步 / 本地 / 同步冲突”，支持搜索、列宽调整和窄窗返回列表。
- 草稿删除图标位于编辑工具栏最右；确认后只删本地草稿，不删除服务器原件或冻结发送记录。后台校验账号、版本及上传/冲突保护，响应丢失后查询原请求结果。
- 服务器原件与冲突从草稿列表“更多”进入；移除独立写信、账号、设置、服务器草稿、发送任务及待同步操作子窗口，继续复用原业务模块。
- 发送状态显示在邮件阅读区收件人旁；右下角图标浮层显示未完成操作、草稿上传和发送任务，每3秒自动刷新，点外部隐藏。查询失败保留上次结果并提示，不误报同步完成。
- 页面、阅读/写信切换、选中颜色、常规文件夹展开收起与箭头、写信辅助区、账号表单和主题均有 M3E 动效。开启“减少动态”时立即到达最终状态；遵循系统减少动态及省电策略。单账号目录超过128节点时直接显隐，避免大量隐藏节点逐帧采样。
- 关闭主窗口保存并退出前台，后台和托盘继续工作；“保存并退出”停止前后台。通知、隐私、可选自启动和缓存管理沿用已有设置。

## 数据与发送边界

草稿、服务器原件、未完成任务和发送快照保留既有保护；不因整理项目而修改用户数据。服务器草稿存在并发冲突时保留副本，不静默覆盖。离线操作可靠落盘后显示本地结果；UIDVALIDITY 改变、结果不确定和认证异常需要核对或处理。

发送必须经预览和明确确认。重连、重启、恢复网络、状态刷新均不得自动重发。普通扫描不会重新导入已删除的同一草稿本地副本；用户仍可明确转换保留的服务器原件。

## 安装与升级

安装包为 `qingmail-1.0.0-1-x86_64.pkg.tar.zst`，附源码快照、PKGBUILD、.SRCINFO、BUILD-INFO 和 SHA256SUMS。先在旧版“保存并退出”，再使用 `sudo pacman -U /绝对路径/qingmail-1.0.0-1-x86_64.pkg.tar.zst`。不自动安装到主机。

需要匹配 GPU 的 Vulkan 驱动、Wayland、会话 D-Bus 与可解锁的 Secret Service。完整依赖、升级、卸载和数据保留说明见安装包随附的 `README.md`（源码位置 `packaging/arch/README.md`）。
