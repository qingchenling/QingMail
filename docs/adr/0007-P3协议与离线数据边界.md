# ADR-0007：P3 IPC v1、持久操作与资源边界

- 日期：2026-11-17
- 状态：接受（用户批准 P3 设计与实施计划）
- 关联：ADR-0003、ADR-0004、ADR-0005；设计详见 `docs/design/P3-001-多账号离线与IPC设计.md`

## 决策

1. P3 先冻结可编译 IPC v1 再拆单账号进程；NDJSON 控制、有界二进制资源传输。领域 DTO 从存储实现中提取，storage 重导出原路径；protocol 不依赖 storage/service/GPUI。
2. daemon 是网络/存储/发送/资源状态唯一管理者。UI 仅呈现、编辑和桌面文件交互；账号秘密通过 Secret Service staging 引用交接，控制协议不承载原始凭据。
3. 离线操作与本地覆盖层事务落盘后乐观显示；重启/重连校验结果，非幂等操作结果不明不盲重放。SMTP 继续 ADR-0005，不加入自动重连发送队列。
4. 草稿双向同步，共同基线冲突保留两份，不自动合并或猜测删除；无法安全替换时保留旧版本。
5. 正文/附件分开按需获取，正文安全限制继续，不能以抬高整封 MIME 上限代替分段实现。缓存默认1GiB，保护草稿/发送快照/未完成任务/冲突原件及在途传输。

## 影响

产生一次有备份的增量存储迁移和两次集中端到端验收。协议版本1不表示全部消息已接入；Hello 明确能力集，未接入命令返回 Unsupported，阶段报告按实际证据记录。OAuth/通知/自启动/打包/性能专项仍属P4。
