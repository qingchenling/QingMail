# 项目状态

更新：2026-11-19。当前交付版本 **1.0.0**，面向 Arch Linux / Hyprland / Wayland。P0/P1 已验收、P2 已完成、P3 用户验收通过，P4 功能及后续主窗口整合已实现。版本、安装、界面变更见 [发行说明](发行说明.md)，本轮构建与整理结果见 [交付记录](reports/1.0.0-交付与整理.md)。发布版本号不替代下列尚未完成的兼容和持续使用验收。

## 已交付

| 部分 | 当前实现 |
| --- | --- |
| 架构 | 7 crate；UI + 独立 daemon；Unix socket / IPC v2；后台唯一数据库所有者，schema19 |
| 邮箱 | 多账号树、统一收件箱、滚动追加本地缓存、三范围本地搜索、账号隔离及独立同步/暂停/退避 |
| 阅读与操作 | 选信直接阅读、启动同步、分段正文/CID、独立附件下载、持久离线队列及冲突/不确定结果处理 |
| 写信 | 主窗口右侧内嵌编辑（取代独立写信窗口）、多草稿、受控富文本、附件、回复/转发、显式发送、禁止自动重发；服务器草稿发现/导入/上传/冲突保留 |
| 缓存 | 默认1GiB、引用保护、LRU及清理；不删除草稿、发送快照或冲突原件 |
| 桌面 | M3E、左侧直角账号文件夹树、托盘/生命周期、通知/隐私/定位、可选后台自启动 |
| 动效 | 页面与阅读/写信切换、选中颜色、常规文件夹展开收起/箭头、写信辅助区淡入及主题过渡；复用 Material Expressive，遵循应用/系统减少动态及省电策略，见[发行说明](发行说明.md) |
| 状态入口 | Drafts 文件夹以三栏显示账号草稿列表和右侧编辑，服务器原件/冲突收进“更多”；本地删除明确确认并保留远端；收件人行显示对应邮件发送状态；右下角同步浮层每3秒自动聚合邮件变更、草稿上传和发送任务，读取失败保留旧数据并提示错误 |
| 性能 | 受控五账号长测及分页/窗口专项；后台最大PSS16.98MiB、单核CPU均值0.452%，只对报告所列条件成立 |
| 安装 | 1.0.0 Arch包、配套UI/daemon、桌面入口/图标、源码快照与校验和；本轮仅隔离验证，不自动安装至主机 |

## 尚未完成的验收

这些是既有范围的验证，不作为新功能立项：

- P4阶段一次全量测试和集中跨功能E2E；修复后仅补跑受影响部分。
- 真实通知弹窗、点击定位、设置交互、重新登录自启动、桌面菜单启动及真实安装升级体验；隔离包事务不代替干净系统验证。
- 100/125/150/200%缩放与中文IME/选区、平铺/窄窗/跨屏；休眠恢复、真实网络切换及省电/平衡切换。
- 新信、历史同步、下载和草稿上传的非空闲峰值与恢复时间。
- 第二真实账号、独立第二客户端草稿冲突及真实断网/磁盘满的跨功能兼容；已有模拟结果不能替代真实记录。
- 建议约7天的真实持续使用，按实际区间和中断记录，不以短时自动化冒充。

此前真实账号仅授权收信与草稿测试，真实SMTP发送须另获授权。完整事实和限制见 [验证记录与已知限制](验证记录与已知限制.md)。

## 后续边界

不默认增加 OAuth、会话聚合、联系人、日历、AI、PGP、复杂编辑器或 GUI 重设计。许可证、公开分发资格、发布签名与兼容政策仍属P5准备，不因本次整理视为完成。中文斜体与富文本剪贴板等已知限制继续保留，不自动立项替换字体或编辑器。

当前运行、构建及安装入口见 [README](../README.md)；主基线、模块地图和ADR分别维护需求、实现位置和决策。只在本页维护“当前状态”，不再新增按阶段命名的当前待办副本。
