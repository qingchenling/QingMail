# 项目状态

更新：2026-11-20。当前交付版本 **1.0.1**，面向 Arch Linux / Hyprland / Wayland。P0/P1 已验收、P2 已完成、P3 用户验收通过，P4 功能及后续主窗口整合已实现。版本、安装、界面变更见 [发行说明](发行说明.md)，本轮构建与整理结果见 [交付记录](reports/1.0.1-构建交付.md)。发布版本号不替代下列尚未完成的兼容和持续使用验收。

1.0.1已接入 Outlook / Hotmail 与 Microsoft 365 的浏览器 OAuth 登录、自动令牌刷新和 XOAUTH2；已内置用户提供的应用 ID，真实兼容未验收，见 [接入说明](Outlook邮箱接入.md)。本版包含 [草稿与删除调整](reports/草稿共用布局与删除同步.md)；从1.0.0（schema19 / IPC v2）升级时需一起更新新前后台。

后续源码已按[草稿生命周期规格](design/草稿生命周期与冲突处理.md)修复保存、未知上传、冲突及删除的状态交叉，冲突界面收敛为单份草稿的版本选择；源码升级至schema23 / IPC v4，配套调试前后台已构建，未重新打包，真实服务器恢复与冲突界面仍待复验。见[修复记录](reports/草稿上传恢复与本地删除修复.md)。

本轮默认设置调整：发送后保存到发件箱默认开启，schema23升级会一次性启用此偏好，但不改变已有发送任务；之后手动关闭会持久保存。阅读设置新增默认开启的“自动加载邮件内图片”，沿用地址及资源限制，关闭后保留单封手动入口。未重新打包，见[设置调整记录](reports/默认发件箱保存与邮件图片设置.md)。

简化阅读已修复行内标签误变段落、冗余空段、图片集中堆放和布局表格误作网格；图片失败提示区分Fake-IP/DNS/HTTP等原因，保留私网限制。图片加载遇到Fake-IP时改用固定引导地址的加密DNS获取真实公网地址，无需修改代理配置。11项图片/DNS定向测试通过，真实缓存邮件的两张图片经实际加载入口均成功（约2秒）；原生视觉效果仍待用户复验，见[排版修复记录](reports/简化阅读排版修复.md)。

保存并退出补齐远程图片与IDLE只读连接取消，并先停止各后台调度再等待收尾。相关11项测试及隔离原生窗口计时通过（空闲前后台退出约0.77秒）；真实账号在途写操作仍须安全完成。调试版前后台已构建，未打包，见[退出优化记录](reports/保存并退出等待优化.md)。

## 已交付

- P4阶段一次全量测试和集中跨功能E2E；修复后仅补跑受影响部分。
- 真实通知弹窗、点击定位、设置交互、重新登录自启动、桌面菜单启动及真实安装升级体验；隔离包事务不代替干净系统验证。

- 新信、历史同步、下载和草稿上传的非空闲峰值与恢复时间。

- 建议约7天的真实持续使用，按实际区间和中断记录，不以短时自动化冒充。

此前真实账号仅授权收信与草稿测试，真实SMTP发送须另获授权。完整事实和限制见 [验证记录与已知限制](验证记录与已知限制.md)。
