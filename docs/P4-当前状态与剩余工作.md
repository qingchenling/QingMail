## 验收事实与范围

P3 用户验收通过与历史测试证据分别记录：单真实账号收信/草稿和隔离集中验证已有证据，第二真实账号、独立第二客户端草稿冲突和真实磁盘满等场景未因此变为已测。后续集中验证继续区分真实/模拟，不把它们重新包装成 P2 待办。详见 [P3 总结](reports/P3-阶段总结与验收边界.md)。

P4 不默认接入 OAuth，不增加通知中心/规则/声音、系统服务、自动更新或 GUI 重设计。现有中文斜体、富文本剪贴板限制继续记录。此前真实账号授权仅收信与草稿，任何真实 SMTP 测试须另获授权。

通知实现及自动证据见 [P4-002报告](reports/P4-002-桌面通知与隐私设置.md)。自启动/安装包尚未实现，仍无 P4 性能达标证据；P3 短时资源样本不替代五账号长期测量。建议 7 天持续使用只在实际发生后记录。

升级：IPC v2 / schema18；先保存并退出旧前后台，再同时更新两个程序。旧P3测试包不能连接新后台或读取新库，详见 [ADR-0008](adr/0008-桌面通知协议v2与持久去重.md)。
