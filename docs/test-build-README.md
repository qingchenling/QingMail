# QingMail 单邮箱测试版

测试包：0.1.0-p2-test2 · 2026-11-17 · Linux x86_64 / Arch / 原生 Wayland。
Rust 源码版本与构建时间见 `BUILD-INFO.txt`。程序本身 `--version` 显示基础版本 0.1.0。

用于验证一个通用 IMAP/SMTP 邮箱的日常使用：启动收信、文件夹、直接阅读、搜索、写信、草稿、发送与已发送副本。包含 UI-001 最新 M3E 邮箱界面；不含多账号与 Gmail/Outlook OAuth。

## 1. 启动

先从旧版 QingMail 的菜单选择“保存并退出”，再启动本包，避免单实例机制把打开请求交给旧进程。解压后在包目录运行：

```sh
sha256sum -c SHA256SUMS
./run-qingmail.sh
```

启动脚本沿用当前 Wayland 会话；Intel Vulkan 驱动存在时默认使用它。可显式覆盖 `VK_DRIVER_FILES`。需要可用的系统 Secret Service 密钥库和动态库；这是本机测试包，不是跨发行版的独立安装包。

默认使用现有 QingMail 的本地账号、邮件缓存与草稿。若想使用独立且可跨重启保留的测试数据，始终用同一个目录启动：

```sh
QINGMAIL_P0_DRAFT_ROOT="$HOME/.local/share/qingmail-single-account-test2" ./run-qingmail.sh
```

账号/缓存/草稿/任务保存在该目录的 `p2-data/` 下；密码仍在系统密钥库，主题等设置仍在正常配置目录。这个选项不隔离网络或密钥库。测试期间不要删除数据目录。

关闭主窗口后后台继续，托盘或再次运行脚本可重开。退出用菜单“保存并退出”，或在相同环境下运行 `./run-qingmail.sh --quit`。第二次启动仍应沿用上面的数据目录选项。

## 2. 配置一个邮箱

1. 打开“账号管理”，填写显示名称、邮箱地址及 IMAP/SMTP 主机、端口、用户名、密码或服务商要求的应用专用密码。
2. 检查 TLS/STARTTLS 与认证；“检查连接”不会发送邮件。检查通过后确认保存。
3. 已配置账号的每次新进程启动会立即刷新目录并同步；之后默认60秒轮询。首次保存账号后可在顶栏更多菜单刷新服务器文件夹，再点击同步；没有立刻出现时重开主窗口。
4. 点击收件箱里的邮件直接阅读；首次读取会下载正文，已有缓存可离线打开。

发送确认会真实投递，归档/删除/标记会操作服务器。发送测试先使用自己的收件地址。

## 3. 日常使用测试

建议按以下顺序测试，在发现问题时记录步骤和界面提示。

- **启动和收信**：完全退出再启动，无需点击同步即可更新目录和邮件；从其他客户端给自己发一封测试邮件，等自动收信出现；重启后账号、目录和缓存仍在。
- **阅读**：连续点击不同邮件、上下键选信，正文始终对应当前选择；切换文件夹、搜索结果或翻页后不残留另一封正文。测试中文、HTML、纯文本、CID 图片、字号、附件另存及“在浏览器中打开”。
- **查找和操作**：搜索关键词/发件人、展开高级筛选；清除后恢复列表。测试单封及批量已读、星标、归档、删除，随后在网页邮箱核对；删除需要确认，标记可撤销。
- **草稿与发送**：新建草稿，填写 To/Cc/Bcc、主题、正文和附件；保存、关闭再重开，确认内容恢复。检查回复/回复全部/转发的新草稿；发送预览确认后发到自己的地址，核对实际收到、发送任务结果与服务器已发送副本。
- **断网与恢复**：已缓存邮件可离线阅读，错误有提示；联网后可手动同步。发送失败或结果不确定时不会自动重发；只有用户明确确认才重新发送。已发副本待保存时，仅重试副本。
- **界面与退出**：明暗主题、列表密度、窄窗返回列表、分隔线拖动；关闭主窗后托盘重开；保存并退出后再次启动，草稿与任务保留，旧任务不自动重新投递。

## 4. 已知限制

- 单账号通用 IMAP/SMTP；无 OAuth、统一收件箱和独立 daemon。
- 正文按完整 MIME 下载，上限8MiB，附件随正文获取；尚无独立分段附件下载。
- 回复未设置 `In-Reply-To`/`References`，收件端可能不串会话。
- 中文斜体字形、系统富文本剪贴板仍有限制；主题不跟随系统。
- 不持久化窗口尺寸、分隔宽度或滚动像素；移动/删除没有撤销。
- 正文下载在途时，连续选信合并为最后一封，等待在途任务结束后加载。
- 已有自动测试与合成原生回归不代替本次真实邮箱测试结论。

## 5. 问题反馈

记录测试包版本、发生时间、操作步骤、期望/实际结果及界面提示。崩溃时可运行：

```sh
RUST_BACKTRACE=1 ./run-qingmail.sh 2>&1 | tee qingmail-test.log
```

使用独立数据目录时，在该命令前加同一 `QINGMAIL_P0_DRAFT_ROOT`。反馈前去掉密码、完整邮件内容及个人地址等敏感信息；如涉及重复发送，保留对应发送任务状态。
