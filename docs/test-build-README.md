# QingMail 单邮箱测试版

测试包：0.1.0-p3-002-test1 · 2026-11-17 · Linux x86_64 / Arch / 原生 Wayland。
源码提交、构建时间见 `BUILD-INFO.txt`。包内 **mail-ui 与 mail-daemon 必须一起更新并放在同一目录**。

用于测试一个通用 IMAP/SMTP 邮箱的启动收信、文件夹、直接阅读、搜索、写信、草稿、发送与已发送副本。本版完成 P3-002 独立后台拆分，沿用 M3E 界面；多账号、离线操作队列、服务器草稿同步尚未实现。

## 1. 启动与退出

先在旧版选择“保存并退出”，确认旧 QingMail 进程已结束，再启动本包。旧进程内后台与新 daemon 不能同时占用同一数据库。

```sh
sha256sum -c SHA256SUMS
./run-qingmail.sh
```

前台自动连接 daemon，缺失时启动同目录 `mail-daemon`，就绪后打开主窗；每次启动请求一次合并同步。第二实例激活现有前台，不启动第二个数据库写者。脚本沿用 Wayland 会话与系统省电策略，Intel Vulkan 驱动存在时默认使用它，可显式覆盖 `VK_DRIVER_FILES`。

关闭主窗会先保存编辑窗口，再退出前台进程；保存失败则保留窗口。daemon 与托盘继续运行，托盘或再次运行脚本可重开。完全退出用“保存并退出”或 `./run-qingmail.sh --quit`；`--status` 查看后台状态。没有托盘宿主时，界面显示重新打开和退出方式。后台崩溃后界面显示连接错误，重启后台后恢复会话，不重放未确认的写操作：

```sh
./mail-daemon --production
```

该命令也可用于直接查看启动/迁移错误。需要系统 Secret Service 密钥库及动态库；这是本机测试包，不是跨发行版安装包。

## 2. 数据与迁移

默认沿用 XDG 下的 QingMail 数据、账号、草稿和发送任务，密码留在系统密钥库。schema8→9→10 顺序迁移，升级前自动创建私有备份；拒绝打开未来 schema。当前这一轮不再修改 schema。旧版二进制可能拒绝已升级数据库，请保留备份，不直接覆盖回旧库。

如要使用独立的真实邮箱测试数据，先完全退出全部 QingMail 进程，随后每次使用相同环境启动：

```sh
XDG_DATA_HOME="$HOME/.local/share/qingmail-p3-test" ./run-qingmail.sh
```

数据库位于该目录的 `qingmail/`；配置、运行 socket 和系统密钥库仍按正常 XDG/桌面环境使用。不要同时运行默认数据与测试数据的后台；不要在运行中删除目录。`QINGMAIL_P0_DRAFT_ROOT` 仅用于旧隔离诊断，不用于本版正式客户端。

仅验证 GUI/IPC、不连接邮箱时可使用私有绝对目录：

```sh
QINGMAIL_IPC_ROOT=/tmp/qingmail-p3-isolated ./run-qingmail.sh
# 退出时使用同一个变量
QINGMAIL_IPC_ROOT=/tmp/qingmail-p3-isolated ./run-qingmail.sh --quit
```

此模式隔离数据与运行 socket，禁止邮件网络和密钥库访问，默认不启用托盘，不能用来验证真实收发。

## 3. 一个邮箱的测试流程

1. “账号管理”填写邮箱、IMAP/SMTP、TLS/STARTTLS、密码或应用专用密码。“检查连接”不会发送邮件；通过后保存。前台只向 Secret Service 写临时项，后台验证并保存，密码不经 IPC。
2. 重启前台，确认自动同步目录和索引；选信直接显示对应正文，缓存可离线阅读。检查中文、HTML、纯文本、CID、附件另存、安全浏览器副本。
3. 检查文件夹、搜索、已读/星标、归档/删除，并在网页邮箱核对。它们仍是在线操作，失败不会在恢复网络后自动执行。
4. 编辑 To/Cc/Bcc、主题、格式和附件，立即关闭编辑窗或主窗，再重开确认恢复。发送预览确认会真实投递，请自行选择测试收件地址；核对任务及已发送副本。失败、结果不确定、副本待保存都不自动重发。
5. 关闭主窗后检查前台进程退出、daemon/托盘仍在；托盘重开、再次启动、保存并退出后再启动，确认草稿和发送任务保留。

## 4. 已知边界

- 仍为单账号通用 IMAP/SMTP，无 OAuth、统一收件箱、离线操作队列、双向服务器草稿或缓存预算。
- 正文仍按完整 MIME 获取，上限8MiB；附件随正文传输。独立二进制 IPC 资源通道不等于 P3-005 分段下载。
- 草稿正文32KiB、序列化8MiB及原发送附件限制保持不变。草稿列表与发送任务经后台 keyset 分页传输，前台仍聚合为现有列表；不是大型邮箱列表性能专项。
- 前台崩溃后会话租约最多15秒过期，期间再次启动可能只向旧会话请求激活；稍后重开。后台断开时已保存数据保留，重连不恢复发送许可。
- 回复线程头、中文斜体、系统富文本剪贴板、窗口布局持久化等既有缺口仍在；移动/删除没有通用撤销。
- 自动验证使用隔离合成账号与原生窗口；本轮未访问真实邮箱、未真实发送、未以真实密码验证跨进程 Secret Service。

## 5. 问题反馈

记录包版本、时间、步骤、期望/实际结果及提示。前台日志可运行 `RUST_BACKTRACE=1 ./run-qingmail.sh 2>&1 | tee qingmail-test.log`；后台日志可在完全退出后运行 `RUST_BACKTRACE=1 ./mail-daemon --production`。独立数据测试须保留同一 XDG 环境。反馈前删去密码、邮件正文及私人地址；涉及重复发送时保留任务状态。
