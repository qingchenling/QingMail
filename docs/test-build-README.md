# QingMail P2 测试版（第一版可用端到端测试包）

版本：0.1.0（P2 A–E 实现收尾）
日期：2026-11-16
平台：Arch Linux / 原生 Wayland / GPUI + Vulkan；需要可用的 Secret Service。

这个包用于**真实账号端到端验收**，不是稳定发布版。它会连接真实 IMAP/SMTP、读写真实邮件；发送按钮会真实投递。请只在明确授权的测试账号上使用。

## 1. 运行

```sh
./run-qingmail.sh
```

`run-qingmail.sh` 默认使用 `WAYLAND_DISPLAY=wayland-1` 和 Intel Vulkan 驱动；如环境不同可覆盖：

```sh
WAYLAND_DISPLAY=wayland-1 VK_DRIVER_FILES=/usr/share/vulkan/icd.d/intel_icd.json ./mail-ui
```

隔离数据目录（推荐验收使用；仍会使用真实网络与真实 Secret Service）：

```sh
QINGMAIL_P0_DRAFT_ROOT=/tmp/qingmail-p2-e2e ./run-qingmail.sh
```

该目录保存账号、缓存、草稿、对象与发送任务；删除它等于移除本地数据，不会删除远端邮件。首次运行会创建 `p2-data` 子目录。

退出：主窗口关闭后后台继续；再次运行可重开；`./mail-ui --quit` 保存并退出。
查看版本：`./mail-ui --version`。

## 2. 首次配置

1. 打开“账号管理”，填写显示名称、邮箱地址、IMAP/SMTP 服务器、端口、用户名与密码/应用专用密码。
2. “检查连接”：只验证 TLS/STARTTLS、认证与 IMAP LIST、SMTP AUTH，不发送邮件。
3. 检查通过后“保存账号”；密码写入系统密钥库。
4. 回到邮件主界面，选择文件夹并“同步最近邮件”；自动收信默认 60 秒一次，可暂停。

## 3. 端到端验收清单

按顺序执行并记录结果（通过/失败/条件不足）：

### A. 账号与密钥库
- [ ] 错误密码检查失败，账号未保存，密钥库未被覆盖。
- [ ] 正确密码检查通过并保存；重启后账号仍在，密钥库可读取。
- [ ] 修改 IMAP/SMTP 配置后重新检查并“更新账号”，本地缓存/草稿未丢。
- [ ] 仅更新密码：重新输入并检查后更新，旧密码失效时能恢复。
- [ ] 锁定/停用 Secret Service 时提示明确；解锁后重试成功。

### B. 收信、阅读与搜索
- [ ] 文件夹目录、最近 90 天头部同步；自动收信在 60 秒内出现新邮件。
- [ ] 打开正文（缓存优先、缺缓存下载），附件另存、CID 图片、纯文本/字号、浏览器副本与清理。
- [ ] 搜索关键词、发件人、有附件、当前文件夹/整个账号；清除后恢复原位置。
- [ ] 断网后自动收信显示失败并退避；恢复网络后继续；手动同步可用。
- [ ] 在服务端删除/移动一封已缓存邮件，完整同步后本地列表不再显示（90 天内）。

### C. 基本操作
- [ ] 已读/未读、星标/取消星标；失败时不改本地缓存。
- [ ] 归档、删除（移到已删除）与批量选择；在服务端/网页确认目标文件夹。
- [ ] 当前文件夹位置、分页与选中项在切换文件夹后恢复。
- [ ] 窄窗点击阅读后“返回列表”。

### D. 写信、回复与发送
- [ ] 回复/全部回复/转发：收件人、主题前缀、引用纯文本正确；新草稿不覆盖已有草稿。
- [ ] 收件人 chips 可移除；Cc/Bcc 折叠/展开；错误地址标红到字段。
- [ ] 保存/关闭/重开草稿；附件导入与移除；另存草稿。
- [ ] 发送预览、空主题确认、确认后真实投递到自己的测试地址。
- [ ] 服务器“已发送”出现同一封副本；任务显示 Sent；副本查看可打开。
- [ ] 发送任务窗口：失败/不确定重发需二次确认；停止处理；只重试副本。
- [ ] 发送中断网/关窗/退出重启：不自动重发；状态可恢复。

### E. 账号移除与设置
- [ ] 移除账号前列出缓存/草稿/任务影响；确认后本地数据删除，远端邮件保留。
- [ ] 设置主题/字号/列表密度/减少动态；重启后保持。
- [ ] 退出等待发送结果写盘；再次启动不自动发送。

## 4. 已知限制（本轮不要求通过）

- 附件随整封 MIME 下载（≤8MiB），按部分下载未实现，需操作者确认该取舍。
- 主题不跟随系统；设置文件损坏会静默回退默认。
- 回复不设置 `In-Reply-To`/`References`，收件端不会串会话。
- 分隔宽度与窗口尺寸不持久化。
- 前端浏览器资源行为依赖系统浏览器；不把浏览器内存计入后台。
- 中文斜体缺字形为已接受限制。
