# QingMail P3 测试版

测试包：0.1.0-p3-test1 · 2026-11-18 · Linux x86_64 / Arch / 原生 Wayland。
源码提交与时间见 `BUILD-INFO.txt`。`mail-ui` 与 `mail-daemon` 必须一起更新并放在同一目录。

本版包含独立后台、多账号与统一收件箱、离线邮件操作、按需正文/附件、服务器草稿和缓存预算。真实双账号、独立第二客户端草稿兼容尚待补验收，不宣称 P3 最终验收全部完成。

## 启动与退出

先在旧版选择“保存并退出”，结束旧前后台，然后校验并运行：

```sh
sha256sum -c SHA256SUMS
./run-qingmail.sh
```

前台自动连接或启动后台，每次启动合并请求一次同步。关闭主窗先保存编辑窗口，成功才退出前台；后台与托盘继续运行。托盘或再次启动脚本可以重开。完全退出用“保存并退出”或 `./run-qingmail.sh --quit`；`--status` 查看状态。无托盘宿主时按界面提示重开或退出。

脚本遵循 Wayland 会话与系统省电策略，可显式设置 `VK_DRIVER_FILES`。需要 Secret Service 密钥库和系统动态库；本包不是跨发行版安装包。后台直接启动方式为 `./mail-daemon --production`。

## 数据与迁移

沿用 XDG QingMail 数据目录与密钥库，密码不经 IPC 或普通数据库。schema8～16 顺序迁移到17，升级前自动创建 `migration-v<旧版本>-*.sqlite3` 私有备份；保留对象文件。旧版可能拒绝打开新库。回退须先完整退出、保存当前数据，再配套恢复迁移前数据库及对象；不要在运行中替换数据库或删除对象。

隔离验证（不访问真实账号/密钥库、不联网）：

```sh
QINGMAIL_IPC_ROOT=/tmp/qingmail-p3-isolated ./run-qingmail.sh
QINGMAIL_IPC_ROOT=/tmp/qingmail-p3-isolated ./run-qingmail.sh --quit
```

真实测试使用另外的数据目录时，每次启动保持相同 `XDG_DATA_HOME`，并先完全退出旧后台；运行 socket 仍共用当前桌面会话，不能同时运行两份正式后台。

## 功能与操作

- 在账号管理中添加通用 IMAP/SMTP 账号，配置默认发件账号或暂停账号。统一收件箱保留各账号身份；回复沿用原邮件账号，草稿不自动跨账号。
- 点击邮件直接阅读；正文与附件分开获取。未缓存时需要联网。附件点击后下载，可取消；失败或半份内容不标为已下载。
- 已读、星标、归档与删除先持久保存并显示待同步。“待同步操作”可查看失败、冲突及结果不确定。移动结果不明时先核对，不盲目重试。
- 本地草稿立即保存，停止编辑约5秒后调度服务器同步。唯一 Drafts 特殊用途目录自动选择，缺失或有歧义时在“服务器草稿”中明确选择。
- 草稿并发变化保留原件与冲突副本，可查看两份并明确选择。未知上传只查询原标识；转换副本不会覆盖原件。服务器旧版本可能保留，不做全局 EXPUNGE。
- 设置中查看缓存用量，选择256 MiB、1 GiB（默认）或4 GiB预算；清理需再次确认。只清理可下载正文/附件，保留索引、草稿、发送快照、冲突原件和未完成操作。受保护内容超过预算会提示，不自动删除用户内容。
- 浏览器阅读副本独立清理，不计入上述对象预算。下载临时文件及已打开的导出句柄可能暂时占用额外空间，完成/取消、资源失效或进程退出后释放。
- 恢复联网、重启和重连均不会自动重发 SMTP。测试发送须操作者明确授权和确认，本轮自动验收未发送任何邮件。

## 已知边界与验收补项

无 OAuth、通知、自启动或安装包。普通完整 MIME 回退≤8 MiB；服务器草稿原件≤40 MiB；收件单附件≤1 GiB。编辑正文32 KiB、序列化8 MiB、原发件附件限制不变。

当前一个已配置真实账号的收信、阅读、草稿上传与未知请求恢复核验已通过；第二账号由操作者稍后添加。独立第二客户端交替/并发编辑、真实断网及磁盘满综合场景仍须集中补验收；模拟故障通过不能替代真实兼容证据。详见 P3-007 报告。

中文斜体、系统富文本剪贴板、回复线程头等既有缺口仍在；移动/删除无通用撤销。本轮不提前宣称 P4 性能预算达成。
